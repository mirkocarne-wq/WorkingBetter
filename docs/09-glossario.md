# 09 — Glossario

| Termine | Definizione |
|---|---|
| **1:1** | Incontro ricorrente tra due persone (tipicamente manager e riporto) con agenda, note e azioni condivise. |
| **9-box** | Griglia 3×3 che incrocia performance e potenziale per la talent review. |
| **Action item** | Attività con owner e scadenza nata da un 1:1, una review o un piano d'azione. |
| **ADR** | Architecture Decision Record: documento che registra una decisione tecnica e le sue motivazioni. |
| **Allineamento** | Relazione "contribuisce a" tra obiettivi di livelli diversi. |
| **App (App Studio)** | Pacchetto form + workflow + permessi + naming che implementa un processo HR. |
| **Calibrazione** | Sessione in cui manager e HR confrontano e allineano i rating prima di renderli finali. |
| **Check-in (KR)** | Aggiornamento periodico del valore e della confidenza di un key result. |
| **Check-in (strutturato)** | Breve questionario ricorrente compilato dal collaboratore prima del 1:1. |
| **Ciclo (periodo)** | Intervallo temporale di riferimento per obiettivi o review (trimestre, semestre, anno). |
| **Competenza** | Capacità o comportamento osservabile, con livelli e descrittori. |
| **Competency framework** | Insieme di competenze e livelli attesi per job e livello di carriera. |
| **Driver (survey)** | Dimensione tematica a cui le domande di engagement sono associate. |
| **eNPS** | Employee Net Promoter Score: % promotori (9–10) meno % detrattori (0–6) alla domanda "Consiglieresti l'azienda come posto di lavoro?". |
| **Fascicolo (profilo persona)** | Vista unificata di obiettivi, review, feedback, 1:1, sviluppo di una persona. |
| **Feedback 360°** | Raccolta di feedback su una persona da più categorie di valutatori. |
| **HRBP** | HR Business Partner: ruolo HR con perimetro limitato a una parte dell'organizzazione. |
| **HRIS** | Human Resources Information System: sistema di record dei dipendenti (es. Zucchetti, Personio, BambooHR). |
| **IDP** | Individual Development Plan: piano di sviluppo individuale. |
| **Istanza (processo)** | Esecuzione di un'app/processo per un soggetto specifico. |
| **Key Result (KR)** | Misura quantitativa del raggiungimento di un obiettivo. |
| **Kudos / Riconoscimento** | Apprezzamento pubblico verso un collega, collegato ai valori aziendali. |
| **Magic link** | Link di accesso temporaneo senza password (usato per valutatori esterni). |
| **Naming personalizzato** | Possibilità del tenant di rinominare i concetti principali nell'interfaccia. |
| **OKR** | Objectives and Key Results: metodo di definizione obiettivi con risultati chiave misurabili. |
| **Perimetro (scope)** | Insieme di unità/persone su cui un ruolo ha effetto. |
| **Pulse survey** | Survey breve e ricorrente per misurare il clima nel tempo. |
| **RBAC** | Role-Based Access Control: permessi assegnati tramite ruoli. |
| **RLS** | Row-Level Security: policy del database che filtra le righe visibili per tenant. |
| **SBI** | Situazione–Comportamento–Impatto: modello per dare feedback strutturato. |
| **SCIM** | Standard per il provisioning automatico di utenti da un identity provider. |
| **Soglia di anonimato** | Numero minimo di risposte necessario per mostrare un dato aggregato. |
| **SSO** | Single Sign-On: accesso tramite identity provider aziendale (SAML/OIDC). |
| **Stale (obiettivo)** | Obiettivo senza check-in oltre la cadenza prevista. |
| **Talent review** | Sessione in cui leadership e HR valutano performance e potenziale (9-box, succession). |
| **Tenant** | Azienda cliente con dati isolati sulla piattaforma. |
| **Template** | Definizione riutilizzabile (di review, survey, obiettivo, agenda, percorso). |
| **Workflow** | Sequenza di fasi con attori, scadenze e regole che compongono un processo. |
| **Welfare aziendale** | Insieme di beni, servizi e somme che l'azienda mette a disposizione dei dipendenti con regimi fiscali agevolati (flexible benefit, fringe benefit, rimborsi, previdenza, sanità). |
| **Conto welfare** | Saldo di credito welfare di una persona, alimentato da fonti di budget e consumato da richieste. |
| **Conversione del premio di risultato** | Scelta del dipendente di trasformare tutto o parte del premio variabile in credito welfare. |
| **Categoria fiscale** | Classificazione di un bene/servizio welfare secondo il regime applicabile (esente, soglia annua, imponibile). |
| **Data mart** | Base dati analitica separata da quella operativa, organizzata a fatti e dimensioni per la reportistica. |
| **Semantic layer** | Strato che definisce le metriche (formula, grana, dimensioni, privacy) in un unico punto, usato da dashboard, report builder e API. |
| **Metrica** | Misura definita nel catalogo del semantic layer (es. eNPS, % completamento review). |
| **Entità custom** | Tipo di record definito dal tenant nell'App Studio (livello L3), ancorato a persona, unità o processo. |
| **Automazione** | Regola evento → condizione → azione configurata senza codice (livello L4). |
